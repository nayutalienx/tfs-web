# Участие в разработке

Проект — независимый локальный TFS-клиент на Go. UI — серверные шаблоны и
небольшой нативный JavaScript без npm, фреймворков и сборки фронтенда.
Интерфейс и пользовательские сообщения сейчас на русском языке.

Перед pull request:

```sh
gofmt -w *.go
go test -race ./...
go vet ./...
node --test static/search_test.cjs
```

Последняя команда необязательна при локальной работе, но выполняется в CI.
Используйте Go 1.26+ и Node.js 22+ для JS-тестов. Добавляйте mock-тесты для
изменений REST-вызовов, CSRF, санитайзеров и поведения при ошибках.

Не запускайте тестовые мутации против настоящего TFS. Fixtures должны быть
синтетическими: `DemoProject`, `https://tfs.example.com/DefaultCollection`,
локальные `httptest`-серверы, вымышленные ID и пользователи. Не прикладывайте
рабочие логи, скриншоты и настройки. См. [SECURITY.md](SECURITY.md).

Сохраняйте работоспособность основных страниц и форм без JS, привязку сервера
к loopback, CSRF/Host/CSP-проверки, защиту от конфликтов записи и отсутствие
автоматических повторов мутаций. Не добавляйте учётные данные в общий конфиг
или Web Storage. Публичный хостинг не входит в текущую модель использования.

В PR опишите цель, изменения, проверки и ограничения. Для UI достаточно
скриншотов с синтетическими данными. Перед отправкой проверьте diff и новые
файлы; не включайте `bin/` и локальные артефакты. Убедитесь, что у вас есть
право публиковать предлагаемый код под MIT-лицензией проекта.
